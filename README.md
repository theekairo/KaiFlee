# KaiFlee 3.8

made by nexus

.gg/znwCgvzBgu

Русский интерфейс для Flee the Facility. Infinite Yield запускается отдельной кнопкой в настройках.

## Запуск

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/theekairo/KaiFlee/main/KaiFlee.lua"))()
```

Для обновления выгрузи старую панель через настройки или перезайди в игру. Повторный запуск поверх существующей панели не обновляет её и не создаёт дубликатов. Правый Shift показывает и скрывает меню.

## Интерфейс

- Профиль с ником и аватаркой удалён вместе с запросом изображения.
- Заголовок KaiFlee расположен по центру окна.
- Порядок ESP: игроки, компьютеры, капсулы, ники игроков.
- «Взлом без ошибок» переименован в «Автовзлом ПК», включён по умолчанию и не имеет подписи.
- Динамические статусы и остальные подписи под функциями удалены. Внутреннее состояние доступно через Control для диагностики.
- Предупреждение об опасности и его радиус удалены.
- Используется штатный Source Sans с фиксированными размерами текста. Масштабирование текста через UIScale удалено; размеры панели подстраиваются под экран, положения анимаций округлены до пикселя. На узком экране вкладки прокручиваются горизонтально.
- Яркое освещение сохранено. Переключатель ESP сквозь стены удалён из меню; подсветка и ники постоянно показываются сквозь стены. Настройки FOV, дальности ESP и радиуса замедления отсутствуют.

## Автоматика и троллинг

Автовзлом ПК автоматически проходит мини-игру при уже начатом взломе компьютера. Для структуры клиента, исследованной в place 893973440 версии 349, считываются TimingCircle/TimingPin и TimingGoalPosition. Внутри правильного сектора воспроизводится штатное действие через SetValue("ActionInput", true) и Input/Action; результат формирует игровой LocalGuiScript. После закрытия мини-игры, выключения функции, смены персонажа или выгрузки действие освобождается. На старой структуре без нужного клиентского API сохраняется прежний режим отправки результата.

Спасение прекращает взаимодействие при смене персонажа или карты; возврат к старым координатам между картами исключён. Повторное приближение к капсуле при коррекции позиции ограничено.

Автоотвязка дополнительно определяет жертву по ObjectValue CarriedTorso в персонаже чудовища. Этот вариант работает в обработчике без обязательного наличия RopeConstraint. Поддержка верёвок по привязкам сохранена. События заново определяются после смены персонажа; ошибки отправки вызывают отложенную попытку. Бюджет троллинга остаётся общим: 32 запроса в секунду. Поддержка обнаруженного состояния ещё не доказывает, что сервер выполнит чужой запрос к молоту.

Замедление чужого чудовища восстановить не удалось. Из текущего клиента считан обработчик PowersLocalScript: он использует тот же Jumped, что и предыдущая версия KaiFlee. В отдельной живой проверке, когда пользователь сам играл чудовищем с Runner, одиночный запрос к собственному PowersEvent изменил WalkSpeed с 17 до 3,4, затем скорость восстановилась до 17. Проба не присваивала WalkSpeed. Это подтверждает действие команды на собственном персонаже, но не на чужом. Различие указывает на возможную привязку серверного обработчика к отправителю; без кода сервера это остаётся выводом, а не установленным устройством проверки.

## Оптимизация и проверки

Сканирование карты распределено по кадрам: до 80 объектов и с бюджетом времени 1 мс на шаг. Один вызов движка может занять больше бюджета. За обновление создаётся до четырёх подсветок, затем они переиспользуются. Неактивные анимации не переписывают свойства каждый кадр. CanvasGroup не создаются.

Версия скомпилирована и проверена анализатором Luau. Моделируемые проверки покрывают интерфейс, значения по умолчанию, запуск с 6000 объектов, выбор правильного сектора, нажатие и освобождение ActionInput, CarriedTorso без RopeConstraint, автоматику, смену персонажа, повторные подключения, бюджет запросов, сброс, выгрузку и параллельный запуск.

31 октября 2026 года в работающем клиенте прочитаны версия игры, состояния игроков, объекты карты, события и доступный клиентский байткод. Серверные Script вернули пустой байткод. Общий обзор остановлен на 30000 объектов, затем выполнен отдельный целевой обзор клиентских обработчиков. Диагностические данные игроков не публикуются.

Версия 3.8 дополнительно запущена в настоящем клиенте. Подтверждены включённый автовзлом по умолчанию и доступность ModuleScript API GetValue/SetValue. Проверка одиночного Jumped выполнена на собственном чудовище. Успешное прохождение новым обработчиком настоящей мини-игры и срабатывание автоотвязки на сервере пока не подтверждены: во время последующей проверки пользователь уже играл чудовищем. Нативный вылет на ноутбуке сестры не воспроизведён.

## Infinite Yield

«Настройки → Запустить Infinite Yield» загружает официальный [EdgeIY/infiniteyield](https://github.com/EdgeIY/infiniteyield). Защита от дубликатов, ошибок и просроченных ответов сохранена. Выгрузка KaiFlee не закрывает отдельно запущенный Infinite Yield.
