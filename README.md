# KaiFlee

KaiFlee — панель для Roblox-игры Flee the Facility с русским интерфейсом. В ней собраны подсветка игроков и объектов, автоматические действия и настройки игры. Infinite Yield можно запустить отдельно из меню.

## Запуск

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/theekairo/KaiFlee/main/KaiFlee.lua"))()
```

Правый Shift открывает и скрывает панель. Чтобы загрузить обновление, сначала выгрузите старую панель в настройках или перезайдите в игру.

## Возможности

- Подсветка игроков, компьютеров и капсул.
- Автовзлом мини-игры после начала работы за компьютером.
- Действия для спасения и автоотвязки.
- Яркое освещение и отдельный запуск [Infinite Yield](https://github.com/EdgeIY/infiniteyield).

Работа отдельных действий зависит от текущей версии игры и серверных ограничений. Возможность замедлять чужого игрока-чудовище не подтверждена.
