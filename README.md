# KaiFlee

made by nexus

Русский интерфейс для Flee the Facility. Один запуск загружает KaiFlee и Infinite Yield.

## Запуск

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/theekairo/KaiFlee/main/KaiFlee.lua"))()
```

Перед обновлением выгрузи старую панель KaiFlee через её настройки.
Повторный запуск не создаёт дубликаты панелей.

- Правый Shift — показать или скрыть KaiFlee.
- F6 — пауза троллинга.
- Ники игроков выключены по умолчанию.

## Статус функций

- Замедление чудовища: не работает стабильно, ожидает исправления.
- Взлом без ошибок: частично работает, возможны пропуски.
- Автоспасение: не проверено в игре.
- Автоотвязка: работа подтверждена пользователем.

Ограничения показаны непосредственно под соответствующими переключателями.

## Infinite Yield

Загрузчик использует официальный источник:
[EdgeIY/infiniteyield](https://github.com/EdgeIY/infiniteyield).
На момент подготовки этой версии проверен Infinite Yield 6.4.2.
Уже работающий Infinite Yield повторно не запускается.
Ошибка его загрузки не останавливает KaiFlee.

## Обновление

Основной файл — `KaiFlee.lua` в ветке `main`.
Загрузчик получает этот файл по постоянному адресу.
